What it does

A replayable producer feeds raw log lines through a parsing, feature-extraction, and scoring pipeline in real time. Three unsupervised detectors (Isolation Forest, PCA reconstruction error, and a small autoencoder) run behind one common model interface, trained only on normal sessions.

Methodology, in brief

01

Literature survey

Field evolution: rule-based → classical ML → deep sequence models → the streaming-framework assumption this thesis questions.

02

Proposed system

An architecture decision rule: template-frequency signal → classical detector is competitive; event-order signal → a sequence model is structurally necessary.

03

Applied case study

LogSentinel implements the proposal and supplies the measured numbers: E1-E8 experiments on HDFS, BGL, and a 20M-line Thunderbird prefix.

04

Comparative results

Self-run PyOD/loglizer benchmarks, cited DeepLog/LogAnomaly/LogBERT figures, and a qualitative placement against ELK/Splunk-style pipelines.

Deployed, this sits as a detection layer feeding a SIEM, not replacing one, and the throughput figures above are single-host. The thesis states that caveat next to the claim, not buried in a limitations section.
